## Laboratorio 2 - Flujo de datos

### Fuente
Se obtuvieron datos meteorológicos de la API pública Open-Meteo
correspondientes a Huancayo.

### Transformación
Los datos JSON fueron convertidos a CSV y posteriormente analizados
utilizando Pandas y NumPy.

### Salida
Se generaron archivos CSV con los datos procesados y un resumen
agrupado por categoría de temperatura.
